Heart models

Textured heart: /models/source/Heart.fbx. Keep the Heart.fbm texture folder beside Heart.fbx inside source.
Reference anatomy: /models/bodyparts3d-heart.glb. It contains separately modeled left and right coronary trees. Attribution and license are in BODY_PARTS3D_ATTRIBUTION.txt.
The textured view uses simplified projected overlays for the simulated device path. The Anatomy view shows generic reference geometry. Both are educational, not clinically validated.
